# Learning Notes

This document records concepts learned during the development of Project Apollo Lake.

The purpose is to build a personal technical knowledge base rather than simply record the final implementation.

---

## GitHub

### Repository

A repository is the main project space containing files and their version history.

### Commit

A commit is a recorded checkpoint in the project's history.

---

## Project Documentation

### Source of Truth

The project's source of truth is the information considered authoritative when different conversations or AI assistants may have different context.

For Project Apollo Lake, GitHub is intended to serve this role.

---

## AI-Assisted Development

AI assistants can help with programming, research, debugging and learning.

However, relying entirely on generated code without understanding it can make a project difficult to maintain or explain later.

Project Apollo Lake therefore aims to use AI as a development partner and teacher rather than as a black-box code generator.
